## Explicação do funcionamento do projeto
O site é composto por uma única página dividida em seções (Perfil, Projetos, Vídeo e Contato). No topo, há um menu de navegação simples que permite saltar diretamente para cada parte da página.

## Descrição do recurso novo adicionado
Como recurso novo, adicionei um vídeo embutido utilizando a tag `<iframe>` do HTML e um efeito visual simples de mudança de cor (`hover`) quando o mouse passa por cima dos blocos de projetos.

## Como esse recurso foi implementado
* **Vídeo via iframe:** Utilizei a tag `<iframe>` do HTML apontando para o link de incorporação de um vídeo do YouTube.
* **Efeito Hover:** No arquivo `style.css`, utilizei a propriedade `:hover` combinada com `transition` para mudar a cor de fundo do bloco do projeto sempre que o cursor do mouse passa por cima dele.
